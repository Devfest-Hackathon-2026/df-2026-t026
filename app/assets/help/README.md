# 使い方のスクショ

使い方のページ（`lib/screens/help_screen.dart`）に出す画像。画面を変えたら、変わった画面だけ撮り直す。

- `wide/`：PC の幅。1280×720、倍率1
- `narrow/`：スマホの幅。390×844、倍率2（縦は要る所まで切り取ってよい）
- 名前は節ごとに決まっている：`new_note`・`input`・`review`・`check`・`history`・`rewind`・`edit`・`share`・`profile`

## 例の中身

どの画像も同じ例でそろえる。登場人物・会社はすべて架空。

- ログインは、撮るためだけに作る ID `help`（名前「あおい」）。共有の相手は `help-senpai`（名前「鈴木」）。メンバーの ID は使わない
- ノート「経費と電話の決まり」

  ```
  ## 経費精算
  - 領収書は月末までに経理に出す
  - 交通費は精算シートに書く
  ## 電話対応
  - 電話は3コール以内に出る
  - 取り次ぎは名前と用件を聞く
  ```

- 記録：11/3 山田課長「急ぎの場合は、交通費はメールで送ってもいい」（補足・書き込んだ）、11/4 自分で「電話を取ったら会社名と名前を言う」を足した、11/5 佐藤さん「電話は3コール以内に出てね」（同じ内容）、11/6 鈴木先輩「領収書は翌月5日までに出せばいい」（食い違い → 11/7 山田課長に聞いて「月末までのまま」）、11/9 高橋さん「電話は5コールまでに出ればいいよ」（食い違い・あとで確認）
- 入力・書き込む前の確認：「佐藤さんから、保留は30秒までと言われた」
- リワインドの未整理メモ：「佐藤さんから、来客の予定は前日までに共有カレンダーに入れると言われた」「コピー用紙は2箱を切ったら総務に頼む」

## 撮り方

1. 上の例だけを入れたメモリ上の API を、普段の API（8787）とは別のポートで立てる。`api/src/seed.ts` の `seedWithHistory` と同じように store に直接入れ、AI は偽物（`fake-ai.ts`）にする。偽物は発言者を「〇〇さん・先輩・店長」などでしか読まないので、例文はその形にする
2. アプリをその API に向けて起動する：`fvm flutter run -d web-server --web-hostname 127.0.0.1 --web-port 8081 --dart-define=API_URL=http://localhost:<そのポート>`
3. Chrome で開いて撮る。スマホの幅は `--force-device-scale-factor=2` で開いた Chrome で、幅を 390 にして撮る。リワインドは `--use-fake-device-for-media-stream --use-fake-ui-for-media-stream` で偽のマイクを使い、未整理メモは localStorage の `flutter.memos` に入れる
4. 押す前の状態（入力・ノートを作る・行の編集）は文字を入れたところで、「書き込む前の確認」は「ノートと照らし合わせる」を押した後の知らせの「確かめる」を押したところで撮る
