# 機能追加の手順

1. 既存実装の確認
   - `docs/adr/` と `docs/spec/` で、外した経緯と戻し方を調べる
   - 見つかったら作り直さず、ADRの戻し方に従って画面に出すことをユーザーに提案する
2. オープンPRとの重複確認（重複していたら author を添えてユーザーに確認する）
3. 関連する仕様・ADRを読む
4. 置き場所を決める
   - フロントで吸収できるならフロントで実装する
   - 新しいライブラリは、選んだ理由とライセンスを記録する
5. テストを書く
6. 検証を行ってからPRを作成する
