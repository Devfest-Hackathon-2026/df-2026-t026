# ボタンの名前

アプリ内のボタンの名前の一覧。使う人が「押すと何が起きるか」を言葉だけで分かるように、名前はここで決めてからコードに入れる。

- 名前を変えたいときは「新しい名前」に案を書き、メモに理由を書く。空欄は今の名前のまま
- 案の名前でコードを直したら、「今の名前」を書き換えて「新しい名前」を空にする。前の名前はメモに「前は「〜」」と残す
- ボタンを足す・名前を変えるときは、この一覧も同じ PR で更新する

## 名前の付け方

- 押した結果を動詞で言う。例：「差分を作る」ではなく「ノートと照らし合わせる」
- 「差分」「反映」「承認」「登録」など、git や業務システムの言葉を使わない
- 同じ操作は、どの画面でも同じ言葉にする。例：言われたことをノートの本文に入れるのは「書き込む」、入力をやめて元に戻すのは「やめる」
- 違う操作に同じ言葉を使わない。例：入力ページの「記録する」（言われたことを残す）と、確認のページの「記録する」（聞いた結果を残す）を分ける
- 画面の他の言葉に合わせる。画面では「言われたこと」「聞く」と言っているので、ボタンも「言われたことを直す」「〇〇 に聞いた」とする

## 表示の言葉

ボタン以外の札・見出し・知らせも、ボタンと同じ言葉で書く。

- 分類の札は「同じ内容」「追加」「補足」「食い違い」（コードの `same` / `addition` / `qualification` / `contradiction`）。前は「追記」「条件付きの補足」「矛盾」で、ノートの行の札や見出しの「食い違い」と合っていなかった
- 発言の状態の札は「書き込み済み」「書き込まない」「未書き込み」「関係なし」（ノートに関わる内容が無かった発言）と、「同じ内容」「あとで確認」「確認済み」。前は「反映済み」「反映しない」「未反映」「差分なし」
- ノートを変えずに記録だけ残したことは「ノートは変えずに、言われた記録として残しました」と言う
- 「教わった」「発話」「書き起こし」は使わず、「言われたこと」と言う
- 数えた数は、数と単位の間を空ける（「3 件」「2 冊」「3 ページ」「2 行」）。日付と助詞の間も空ける（「11/10 に足した」）。名前と助詞の間は空けない（「店長が 11/10 に足した」「かなでから共有」）
- 見出しの数も「あとで確認 3 件」と書き、「あとで確認（3）」にはしない。ボタンとタブは短く「確認リスト 3」「発言 3」にする
- 待っている間の文は「…」で終える（「食い違いがないか確かめています…」）

## サイドバー（`sidebar.dart`）

広い画面で左に常に出る（開け閉めのボタンは無い）。狭い画面では、入力ページの上部バーの三本線（メニュー）を押すと、同じ中身が左から出る。Claude・ChatGPT のサイドバーのように、いちばん上にアプリ名「DiffNote」（サイドバーの中で一番大きく太い文字。押せない）、その下に「言われたことを記録」と「あとで確認」と「ノートを探す」、その下に「ノート」の小見出しと全部のノート、いちばん下に自分と（?）を置く。項目はアイコン（あれば）と文字で、高さをそろえる。選んでいる項目は薄い地色。ノートの並びの所だけスクロールし、自分はいちばん下に固定する。

## あとで確認（`open_checks_screen.dart`）

サイドバーの「あとで確認」から開く。全部のノートのうち、あとで確認があるものを件数とともに並べる。中身は入力ページの「あとで確認」の節と同じ部品。共有されたノートの確認があるときは、自分のノートを「自分が聞くこと」、共有されたノートを「聞かれていること」の小見出しに分ける（自分が人に聞くことと、共有した人から答えを待たれていること（ADR 0017）が混ざって分かりにくいため）。共有されたノートが無ければ小見出しは出さない。

|---|---|---|---|---|---|
| （ノートの題名）あとで確認 N 件 | 項目 | 1冊ずつ。「聞かれていること」では件数の左に持ち主の名前 | そのノートの確認リストへ移る | | 入力ページの「あとで確認」と同じ |

## ノートを探す（`search_screen.dart`）

サイドバーの「ノートを探す」から開く。入力欄に言葉を打つと、その場で全部のノート（共有されたノートも）の題名と本文から探し、当たったノートごとに、当たった行を並べる。探すボタンは置かない。

|---|---|---|---|---|---|

## 入力ページ（`input_screen.dart`）

起動して最初に出るページ。題名の右の「リワインド」のトグルを ON にすると、左の列がリワインドの待ち受けに、右の列（最近の記録）が未整理メモに替わる（ページは移らない）。

「ノートと照らし合わせる」を押すと、入力欄はすぐ空になり、次を書ける。照らし合わせは裏で、押した順に1件ずつ進む。待っている間は、入力欄のすぐ下（リワインドの間は待ち受けの面の下）に、言われたことの付箋に「照らし合わせています…」と小さい文字で添えて並べる（前は返るまで入力欄ごと止まっていた。設計書 0021 の C2）。

照らし合わせが返ったら、同じ場所に結果のカードを出す（新しいものを上）。食い違いは「ノート ／ 言われたこと」を左右（狭い幅では上下）に並べ、相手が確定済みの記録なら確認印と「記録を見せる」文を添える。書き込んだ行と同じ内容は、分類と行を1行ずつ出す。複数のノートにまたがるときは、ノートの題名で分ける。カードは次の結果が出るか、閉じるまで残る（前は画面の下に6秒だけ知らせを出していた。#112）。

誰が言ったか読み取れなかったとき・照らし合わせている間にノートが変わっていて書き込まなかったとき（書き換える行が残っていても、ノートが1行でも変わっていれば書き込まない。ADR 0006）は、ダイアログを割り込ませず、カードの見出しでそう言い（「誰が言ったか分からないので、まだ書き込んでいません」「ノートが変わっていたので、まだ書き込んでいない行があります」。「確かめる」で確認を開いて閉じたあとは「まだ書き込んでいない行があります」）、「確かめる」を主のボタンにする。書き込んだ行とまだの行がまざるときだけ、まだの行に「まだ書き込んでいません」と小さい文字で添える。見出しが食い違いのときは、ボタンの横に「誰が言ったか分かりませんでした」と添える。このカードと、関係するノートが見つからなかったときのカード（「関係するノートが見つかりませんでした」）は、次の結果が出ても消さず、確かめるか閉じるまで残す（前はその場で「ノートに書き込む前の確認」・記録先の選択を開いていた）。確かめることが残ったカードは、ノートの画面の発言から確かめて書き込んだ・確認リストで食い違いを確定したなど、ほかの画面でしたことを今の状態として映し、確かめることが残っていれば残す（前は照らし合わせた時点のまま出し続け、食い違いをほかの画面で確定すると、確かめる入口ごと消えた）。確かめることが無くなれば、ふつうのカードと同じく次の結果で入れ替わる。関係するノートが見つからなかったときのカードは、その文面の未整理メモをほかから記録した・消したら外す（残すと「記録先を選ぶ」からもう1度送れて、同じ発言が2回入る）。

食い違いがあるときは、「確かめる」を主のボタンにする。カードは白い面のまま線で囲まず、見出しはほかのカードと同じ大きさ（`text.title`）にし、目立たせるのは比較（上下の罫線と黄の「／」）と確認印だけにする（#132。前は黄の線で囲み、見出しをページの題名と同じ大きさにしていた）。相手が確定済みの記録なら、確認印（ほかと同じ大きさ）を見出しの横（狭い幅では上）に置き、「記録を見せる」の文を太字で出す。食い違いが無いとき（書き込んだ・同じ内容）は「確かめる」も文字のボタンのまま（審査員の指摘3回目。前は食い違いでも文字のボタンだった）。

相手が確定済みの記録なら、「記録を見せる」の文の下に主のボタン「記録を見せて、ノートのままにする」を置き、カードの上で決着できるようにする。「確かめる」は文字のボタンにする。主のボタンはカードに1つにするので、決着できる食い違いが2つ以上あれば、主にするのはいちばん上のまだ決着していないものだけで、ほかは枠のボタンにする。押したあとは、その食い違いの比較から黄をやめ、確定の記録・見せる文・ボタンの代わりに「確認済み」の札と「11/10 自分が記録を見せた（11/7 店長に確認：1/2で統一）」を出す。食い違いが全部決着したら、「確認リストに入れました」も外す（審査員の指摘4回目。前は「確かめる」→「記録した結果」→「確認リストを見る」→ 確認のページの右をスクロールした先、まで進まないと決着できなかった）。

食い違いの相手が確定済みの記録（ノートの行に確認の印がある、または書き換えられた確定済みの行）のときは、1 の比較のすぐ下にその確認の記録（確認印つき）を出し、その下に相手に見せる「記録を見せる」文と、主のボタン「記録を見せて、ノートのままにする」を出す。記録を見せて済ませるのを主にし、2「誰に確認する？」以下は「もう一度聞くなら」の区切りの下に、中身を変えずに続ける（共有されたノートでは、2「答える」の前の区切りを「自分で答えるなら」にする）。

共有されたノートでは、1「食い違っていること」→ 2「答える」の順にし、「誰に確認する？」（確認先の候補・理由・聞き方の例）は出さない。答える欄ははじめから開いておき、確認した相手と日付の欄は無い（決めた人はログインしている人。ADR 0017）。

## 使い方（`help_screen.dart`）

サイドバー（スマホは三本線のメニュー）のいちばん下の自分の右の（?）から開く。ノートを作る → 言われたことを書く → ノートに書き込む → 食い違いはあとで確認する → 履歴を見る の順に、実際の画面のスクショを添えて並べ、その後に「ほかにできること」（リワインド・ノートを直接直す・共有・名前とアイコン）を置く。スクショは開いた画面の幅に合わせて、PC の幅とスマホの幅で出し分ける。題名は「使い方」にする（前は「使い方（暫定）」）。サイドバーは出さず、戻る矢印で元の画面へ戻る。ボタンは無い。スクショの撮り直し方は `app/assets/help/README.md`。
