# ボタンの名前

アプリ内のボタンの名前の一覧。使う人が「押すと何が起きるか」を言葉だけで分かるように、名前はここで決めてからコードに入れる。

- 「新しい名前」が空欄のものは、まだ見直していない。決めたら書き込み、コードを直したら「今の名前」も書き換えて「新しい名前」を空にする
- ボタンを足す・名前を変えるときは、この一覧も同じ PR で更新する
- 書き出した時点：dev `e58dfe6`（2026-11-08）。オープン中の #34（画面上の「マニュアル」を「ノート」に呼び替え）と #27（PC 向けレイアウト）はまだ反映していない

種類の見方：

| 種類 | 見た目 | コード |
|---|---|---|
| 主 | 塗りつぶし。その画面でいちばん押してほしい操作 | `MoonFilledButton` |
| 枠 | 枠線だけ | `MoonOutlinedButton` |
| 文字 | 文字だけ。控えめな操作 | `MoonTextButton` |
| アイコン | 絵だけ。名前は読み上げ用（`semanticLabel`） | `MoonButton.icon` |

## 入力ページ（`input_screen.dart`）

起動して最初に出るページ。上部のタブで「リワインド」と「整理・入力」を切り替える。

| 今の名前 | 種類 | 出る場所・条件 | 押すと何が起きるか | 新しい名前 | メモ |
|---|---|---|---|---|---|
| マニュアルを確認 | 枠 | 上部のバー右 | マニュアル一覧のページへ移る | | 「確認リスト」「あとで確認」の「確認」と意味が違う |
| マニュアルを登録 | 主 | マニュアルが1冊も無いとき | マニュアル登録のページへ移る | | |
| 直前の発話を残す | 主 | リワインド。常時待ち受けが ON のとき | 押す前の発話を文字に起こし、未整理メモにためる | | 押した後は「話し終わりを待っています…」 |
| （×）メモを消す | アイコン | 整理・入力の未整理メモの右上 | そのメモを消す | | |
| （マイク）音声入力 | アイコン | 入力欄の右下 | 話した言葉を入力欄に書き込む。聞き取り中に押すと止まる | | 聞き取り中は「音声入力を止める」 |
| ファイルを添える | 枠 | 入力欄の下 | PDF・画像を選んで添える | | |
| 写真を撮る | 枠 | 入力欄の下。スマホのときだけ | カメラを開いて写真を添える | | PC では代わりに「貼り付けやドロップでも添えられます」 |
| （×）〇〇を外す | アイコン | 添えたファイルの右上 | そのファイルを外す | | |
| 差分を作る | 主 | 入力欄の下 | 入力を送って記録し、どのマニュアルのどの行が変わるかを AI に判定させ、マニュアルごとに「差分の確認」を開く | | 押した後は「差分を作成中…」。「差分」が通じにくい |
| 記録しない | 枠 | 記録先の選択（関係するマニュアルが見つからなかったとき） | 選択を閉じる。何も記録しない | | |
| 記録する | 主 | 同上。1冊以上選んだとき | 選んだマニュアルに記録し、「差分の確認」を開く | | 確認ページの「確認できたので記録する」と同じ動詞 |
| 入る | 主 | 合言葉の入力（API が合言葉を求めたとき） | 合言葉を送ってアプリに入る | | |

名前のない押せる場所：未整理メモの付箋（入力欄に入れる）、「あとで確認」の各マニュアルの行（確認リストへ移る）、最近の記録の付箋（そのマニュアルを開く）。

## 差分の確認（`review_dialog.dart`）

「差分を作る」「記録する」の後や、マニュアルのページで発言の付箋を押すと開くダイアログ。上に言われたこと、その下に変わる行が1つずつ並ぶ。

| 今の名前 | 種類 | 出る場所・条件 | 押すと何が起きるか | 新しい名前 | メモ |
|---|---|---|---|---|---|
| （×）閉じる | アイコン | 右上 | 発言者と日付を保存して閉じる | | ダイアログの外を押しても閉じない |
| 書き起こしを直す | 文字 | 言われたことの下。まだ反映・確定していないとき | 言われたことを直す欄を出す | | |
| 直すのをやめる | 文字 | 直す欄を出しているとき | 直す欄を閉じる | | |
| 直して差分を作り直す | 主 | 同上 | 直した文で AI の判定をやり直す | | |
| （名前）発言者を〇〇にする | チップ | 「誰が言った？」の下。このマニュアルで言ったことのある人 | 発言者の欄にその名前を入れる | | 画面には名前だけが出る |
| 〇〇 に言われた | 枠 | 発言者の下 | 言われた日を選ぶ | | 「11/8 に言われた」のように今の日付が名前になる |
| 承認して反映 | 主 | 変わる行ごと（追加・補足など） | その行をマニュアルに書き込む | | 発言者が空だと押せない |
| 修正 / 修正をやめる | 文字 | 同上 | 書き込む内容を手で直す欄を出す / 閉じる | | 「書き起こしを直す」と、何を直すかの違いが名前から分からない |
| 反映しない | 文字 | 同上 | その行は書き込まず、発言の記録だけ残す | | |
| 記録だけ残す | 主 | マニュアルと同じ内容だったとき | 本文は変えずに、言われた記録として残す | | 「反映しない」と結果は同じで名前が違う |
| それでも反映する | 文字 | 同上 | 同じ内容と判定されたが、それでも書き込む | | |
| 確認リストを見る | 枠 | マニュアルと食い違ったとき | ダイアログを閉じて確認リストへ移る | | |

## マニュアル一覧（`home_screen.dart`）

| 今の名前 | 種類 | 出る場所・条件 | 押すと何が起きるか | 新しい名前 | メモ |
|---|---|---|---|---|---|
| マニュアルを登録 | 主 | 題名の右（1冊以上あるとき）、または空のときの案内 | マニュアル登録のページへ移る | | |

名前のない押せる場所：各マニュアルの行（そのマニュアルを開く）。

## マニュアルを登録（`new_manual_screen.dart`）

| 今の名前 | 種類 | 出る場所・条件 | 押すと何が起きるか | 新しい名前 | メモ |
|---|---|---|---|---|---|
| この内容で登録する | 主 | 本文の下。題名と本文を入れたとき | マニュアルを作り、そのマニュアルを開く | | 押した後は「登録中…」 |

## マニュアルのページ（`manual_screen.dart`）

狭い画面では上部のタブで「マニュアル」と「発言 N」を切り替える。広い画面では左右に並ぶ。

| 今の名前 | 種類 | 出る場所・条件 | 押すと何が起きるか | 新しい名前 | メモ |
|---|---|---|---|---|---|
| 確認リスト / 確認リスト N | 枠 | 上部のバー右 | 確認リストへ移る | | N は未確認の件数 |
| 閉じる | 枠 | 発言者の名前を押して出る、言われたことの表示 | 表示を閉じる | | |

名前のない押せる場所：「あとで確認 N 件」の札（確認リストへ）、食い違っている行（確認リストへ）、行の横の発言者（言われたことを表示）、確認印（確認の記録へ）、発言の付箋（差分の確認を開く）。

## 確認リスト（`check_list_screen.dart`）

ボタンは無い。「あとで確認」「確認済み」の各行を押すと、確認のページへ移る。

## 確認のページ（`check_screen.dart`）

食い違いを、誰かに聞いて決めるページ。1「食い違っていること」→ 2「誰に確認する？」→ 3「確認できたら記録する」の順に並ぶ。

| 今の名前 | 種類 | 出る場所・条件 | 押すと何が起きるか | 新しい名前 | メモ |
|---|---|---|---|---|---|
| （候補の人） | 行 | 2 の下。AI が出した確認先の候補 | 確認した相手の欄にその人を入れる | | |
| （コピー）コピー | アイコン | 聞き方の例の右 | 聞き方の例をコピーする | | |
| 確認できたので記録する | 枠 | 3 の下 | 記録する欄を出す | | 「記録する」が入力ページと別の意味で出てくる |
| 〇〇 に確認 | 枠 | 確認した相手の右 | 確認した日を選ぶ | | 「11/8 に確認」のように今の日付が名前になる |
| マニュアルのまま / 〇〇の言う通り / 別の内容に決まった | 選択肢 | 「どちらに決まった？」 | どちらに決まったかを選ぶ | | |
| 確定する | 主 | 記録する欄の下。相手を入れたとき | 決まった内容でマニュアルを直し、確認済みにする | | |
