# ボタンの名前

アプリ内のボタンの名前の一覧。使う人が「押すと何が起きるか」を言葉だけで分かるように、名前はここで決めてからコードに入れる。

- 名前を変えたいときは「新しい名前」に案を書き、メモに理由を書く。空欄は今の名前のまま
- 案の名前でコードを直したら、「今の名前」を書き換えて「新しい名前」を空にする。前の名前はメモに「前は「〜」」と残す
- ボタンを足す・名前を変えるときは、この一覧も同じ PR で更新する

## 名前の付け方

- 押した結果を動詞で言う。例：「差分を作る」ではなく「ノートと照らし合わせる」
- 「差分」「反映」「承認」「登録」など、git や業務システムの言葉を使わない
- 同じ操作は、どの画面でも同じ言葉にする。例：言われたことをノートの本文に入れるのは「書き込む」、入力をやめて元に戻すのは「やめる」
- 違う操作に同じ言葉を使わない。例：入力ページの「記録する」（言われたことを残す）と、確認のページの「記録する」（聞いた結果を残す）を分ける
- 画面の他の言葉に合わせる。画面では「言われたこと」「聞く」と言っているので、ボタンも「言われたことを直す」「〇〇 に聞いた」とする

種類の見方：

| 種類 | 見た目 | コード |
|---|---|---|
| 主 | 塗りつぶし。その画面でいちばん押してほしい操作 | `MoonFilledButton` |
| 枠 | 枠線だけ | `MoonOutlinedButton` |
| 文字 | 文字だけ。控えめな操作 | `MoonTextButton` |
| アイコン | 絵だけ。名前は読み上げ用（`semanticLabel`） | `MoonButton.icon` |
| 項目 | 一覧の1行 | `MoonMenuItem` |
| トグル | ON／OFF のスイッチ。名前は読み上げ用（`semanticLabel`） | `MoonSwitch` |
| タブ | 下のタブバーの1つ。アイコンと短い名前 | `MoonButton` |

## サイドバー（`sidebar.dart`）

広い画面で左に常に出る（開け閉めのボタンは無い）。狭い画面では、入力ページの上部バーの三本線（メニュー）を押すと、同じ中身が左から出る。Claude・ChatGPT のサイドバーのように、上に「言われたことを記録」と「あとで確認」、その下に「ノート」の小見出しと全部のノート、いちばん下に自分を置く。項目はアイコン（あれば）と文字で、高さをそろえる。選んでいる項目は薄い地色。ノートの並びの所だけスクロールし、自分はいちばん下に固定する。

| 今の名前 | 種類 | 出る場所・条件 | 押すと何が起きるか | 新しい名前 | メモ |
|---|---|---|---|---|---|
| 言われたことを記録 | 項目 | いちばん上。ペンと四角のアイコンつき | 入力ページへ移る | | アイコンは「新しいチャット」と同じ形で、新しく書き始める所だと分かるように |
| あとで確認 | 項目 | 「言われたことを記録」の下。チェックの並んだアイコンつき（タブバーの「確認リスト」と同じ） | 全部のノートの「あとで確認」をまとめたページへ移る | | 全部のノートのあとで確認の合計の件数が付く |
| ノート | 小見出し | 「あとで確認」の下 | ノート一覧へ移る | | 前は「ノート」の項目。名前が2つにならないよう、項目は作らず小見出しを押せるようにした |
| ＋（読み上げ名「ノートを作る」） | アイコン | 小見出し「ノート」の右 | ノートを作るページへ移る | | 前はノートの並びの最後の「ノートを作る」の項目 |
| （ノートの題名） | 項目 | 「ノート」の下に1冊ずつ | そのノートを開く | | 未確認があれば件数が付く |
| 共有されたノート | 小見出し | 自分のノートの並びの下。ほかの人から共有されたノートがあるときだけ | 押せない | | ADR 0013 |
| （ノートの題名） | 項目 | 「共有されたノート」の下に1冊ずつ。右に持ち主の名前 | そのノートを開く | | 見る・行を直すことだけができる。あとで確認の件数は付けない（確定は持ち主がする） |
| （自分の名前） | 項目 | いちばん下に固定。アイコンつき | 名前とアイコンのページへ移る | | 前はいちばん上。決めていなければ ID |

## あとで確認（`open_checks_screen.dart`）

サイドバーの「あとで確認」から開く。全部のノートのうち、あとで確認があるものを件数とともに並べる。中身は入力ページの「あとで確認」の節と同じ部品。

| 今の名前 | 種類 | 出る場所・条件 | 押すと何が起きるか | 新しい名前 | メモ |

| （ノートの題名）あとで確認 N 件 | 項目 | 1冊ずつ | そのノートの確認リストへ移る | | 入力ページの「あとで確認」と同じ |

| 選んだノートと照らし合わせる | 主 | 同上。1冊以上選んだとき | 選んだノートに記録し、「ノートと照らし合わせる」と同じく書き込むか確認を開く | | 前は「記録する」。押した後の動きは「ノートと照らし合わせる」と同じなので、同じ言葉にする |

名前のない押せる場所：未整理メモの付箋（リワインドが OFF なら入力欄に入れる。ON ならその場で書き直す欄を開く）、「あとで確認」の各ノートの行（確認リストへ移る）、最近の記録の付箋（そのノートを開く）。

## リワインドの待ち受け（`rewind_panel.dart`）

入力ページでリワインドを ON にしている間、書く欄の所に出る面。大きな丸いボタンは常に1つで、待ち受けの状態に合わせて名前が変わる。

| 今の名前 | 種類 | 出る場所・条件 | 押すと何が起きるか | 新しい名前 | メモ |
|---|---|---|---|---|---|
| いま言われたことをメモする | 主 | 大きな丸いボタン。待ち受けているとき | 押す前の発話を文字に起こし、未整理メモにためる | | 前は「直前の発話を残す」。「発話」は画面の他の場所で使っていない |
| 待ち受けを始める | 主 | 大きな丸いボタン。マイクを使えなかった・待ち受けが止まったとき | マイクを開き直して待ち受けを始める | | 前は枠のボタンを別に出していた。ボタンを1つにし、場所を変えない |

押せない間の名前：マイクの準備中は「マイクを準備しています…」、押した後は「話し終わるのを待っています…」。

## ノートに書き込む前の確認（`review_dialog.dart`）

| 言われたことを直す | 文字 | 言われたことの下。まだ書き込み・確定していないとき | 言われたことを直す欄を出す | | 前は「書き起こしを直す」。直すのは「書き込む内容」ではなく「言われたこと」だと分かるようにする |

| （名前）発言者を〇〇にする | チップ | 「誰が言った？」の下。このノートで言ったことのある人 | 発言者の欄にその名前を入れる | | 画面には名前だけが出る |

## ノートを消す確かめ（`manual_screen.dart`）

ノートのページの「…」→「ノートを消す」から開く。題名は「このノートを消しますか？」、本文は「「（ノートの題名）」と、記録・確認・履歴がすべて消えます。共有している人からも見えなくなります。元に戻せません。」。消すとどこから開いていても、ノートとその上の画面を外してノート一覧へ移り、「ノートを消しました」と知らせる。失敗したら知らせて、ノートは残す（ADR 0014）。

| 今の名前 | 種類 | 出る場所・条件 | 押すと何が起きるか | 新しい名前 | メモ |
|---|---|---|---|---|---|
| 消す | 主 | 本文の下の左 | ノートと、その記録・確認・履歴・共有をすべて消す。元に戻せない | | 危ない操作なので地は赤（`removed`）。押した後は「消しています…」で、「消す」も「やめる」も押せない（二重に送らない） |
| やめる | 枠 | 「消す」の右 | 何もせずに閉じる | | |

## 共有のモーダル（`share_dialog.dart`）

ノートのページの「共有」から開く。相手のログイン ID を入れて足すと、すぐ相手のサイドバーに出る（招待や承認は無い）。共有された人は、ノートを見ることと行を直接直すことだけができる（ADR 0013）。

| 外す | 文字 | 共有している相手ごと | その人への共有をやめる。相手はこのノートを読めなくなる | | |
| 閉じる | 枠 | いちばん下 | モーダルを閉じる | | 発言の表示の「閉じる」とそろえる |

## 下のタブバー（`tab_bar.dart`）

サイドバーが出ない狭い画面で、ノート・確認リスト・履歴の画面の下に浮かせて出す。後ろが透けてぼける（UI ルールの例外。`--dart-define=TABBAR_BLUR=false` でぼかしを切れる）。押しても横から出てくる動きは付けない。キーボードが出ている間は隠す。

ノートの版を幹、食い違いを枝にしたグラフ。広い画面では左にグラフ、右に選んだ版か食い違いの詳細を並べる（ADR 0008）。

| 今の名前 | 種類 | 出る場所・条件 | 押すと何が起きるか | 新しい名前 | メモ |

## 確認リスト（`check_list_screen.dart`）

ボタンは無い。「あとで確認」「確認済み」の各行を押すと、確認のページへ移る（広い画面では右に並べて出す）。「確認済み」の行には、誰がいつ確認したかを「〇〇 日付 に確認」の形で出す（前は小さい確認印）。

## 確認のページ（`check_screen.dart`）

食い違いを、誰かに聞いて決めるページ。1「食い違っていること」→ 2「誰に確認する？」→ 3「聞いた結果を記録する」の順に並ぶ。

|---|---|---|---|---|---|

| （コピー）聞き方をコピーする | アイコン | 聞き方の例の右 | 聞き方の例をコピーする | | 前は「コピー」。何をコピーするかを読み上げで分かるようにする |
| 聞いた結果を記録する | 枠 | 3 の下 | 記録する欄を出す | | 前は「確認できたので記録する」。入力ページの「記録する」と区別する。見出しも前は「確認できたら記録する」 |
| 〇〇 に聞いた | 枠 | 確認した相手の右 | 確認した日を選ぶ | | 前は「〇〇 に確認」。「〇〇 に言われた」と形をそろえる |
| ノートのまま / 〇〇の言う通り / 別の内容に決まった | 選択肢 | 「どちらに決まった？」 | どちらに決まったかを選ぶ | | |

## 使い方（`help_screen.dart`）

上部のバーの（?）から開く。ノートを作る → 言われたことを書く → ノートに書き込む → 食い違いはあとで確認する → 履歴を見る の順に、実際の画面のスクショを添えて並べ、その後に「ほかにできること」（リワインド・ノートを直接直す・共有・名前とアイコン）を置く。スクショは開いた画面の幅に合わせて、PC の幅とスマホの幅で出し分ける。画面は今後変わるので、題名は「使い方（暫定）」にする。サイドバーは出さず、戻る矢印で元の画面へ戻る。ボタンは無い。スクショの撮り直し方は `app/assets/help/README.md`。
