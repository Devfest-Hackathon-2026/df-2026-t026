# 0018 記録した人を残し、記録を直せるのは記録した本人だけにして、使った記録は固定する

- 日付：2026-11-10
- 状態：採用

## 背景

- 発言の記録には「言った人（`speaker`）」しかなく、だれがその記録を入れたかは残していなかった（ADR 0016 の割り切り）。全員で共同編集すると、ノートに入った行がだれの聞き取りなのかを追えない。
- 共有した全員が、ほかの人の記録の言われたこと・発言者・日付を直し、書き込む・書き込まないを決められた。言われたことの文面は、書き込んだ・確定した後は直せないが、発言者と日付はいつでも変えられ、「誰が言ったか」の証拠が後から変わりうる。

## 決定

1. **記録した人を残す**
   - 発言の記録に `recordedBy`（`{id, name}`。ログイン ID と、その時点の名前）を付ける。入力ページ・ノートからの記録、直接の編集、確定の答えのすべてに付ける。名前は記録した時点のものを残す（ADR 0013 の `speaker` と同じ）。
   - 前からある記録には無い。その記録を記録した人は、共有された人の直接の編集なら `editedBy`、それ以外はノートの持ち主とみなす。
   - 画面では、発言者の名前を押して出る言われたことの表示と、確認のページの元の発言の横に「記録した人：〇〇（11/10）」を出す。
   - ノートの API の応答に、読んでいる人のログイン ID（`me`）を足す。画面が「自分の記録か」を決めるのに使う。
2. **記録を直す・書き込むかを決めるのは、記録した本人だけ**
   - 言われたこと・発言者・日付を直す（`PATCH /manuals/:id/utterances/:uid`）、書き込む（`.../patches/:pid/apply`）、書き込まない（`.../patches/:pid/discard`）は、その記録を記録した人にだけ許し、ほかの人には 403 を返す。
   - ほかの人がノートの付箋を押すと、書き込む前の確認ではなく、言われたことと記録した人を見せるだけにする。
   - 食い違いの確定は、今までどおり全員ができる（教える人が答えるため。ADR 0017）。
3. **書き込んだ・確定した記録は、本人も直せない**
   - 差分を書き込んだか、食い違いを確定した記録は、ノートや確認の記録の証拠なので、言われたことに加えて発言者と日付も直せなくする（409）。書き込む前の確認でも、発言者と日付を入れる欄を出さずに見せるだけにする。
4. **ノートの行は、今までどおり全員が直せる**
   - 直接の編集は止めない。だれがいつどう変えたかはパッチと記録した人で残り、履歴（ADR 0008）で追える。

## 理由

- 聞き取りの正しさを判断できるのは、その場で聞いた本人だけ。ほかの人が発言者や中身を直せると、記録が本人の聞き取りでなくなる。
- 証拠として使った後の記録が変わると、確認印やノートの行の出どころが後から変わってしまう。固定しておけば、記録が証拠になる（spec）。
- ノートの行まで本人に限ると、共有した全員で直す（ADR 0016）が成り立たない。git と同じく、止めるより「だれが変えたか」を残して追えるほうがこのアプリに合う。

## 採らなかった案

- 記録の中身を直すことだけを本人に限り、書き込む・書き込まないは全員ができる：ほかの人の聞き取りを、その人の知らないうちにノートに入れることになる。
- 記録を直したら前の中身を版として残す：変えられても後から分かるが、証拠を変えられること自体は防げない。使う前の記録は本人の下書きなので、版まで残す必要は無い。
- 持ち主はだれの記録でも直せる：共同編集では持ち主も参加者の一人で、ほかの人の聞き取りを変えられる理由にならない。

## 割り切っていること

- 記録した人が共有から外されると、その人の未処理の記録（書き込むかを決めていない差分）はだれも書き込めない。食い違いなら確定はできる。
- 前からある記録は、だれが記録したかを推し量っている（共有された人の直接の編集以外は持ち主）。
- 履歴の画面にはまだ記録した人を出していない。
