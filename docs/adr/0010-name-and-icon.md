# 0010 名前とアイコンを利用者ごとに持つ

- 日付：2026-11-09
- 状態：採用

## 背景

- ログイン（ADR 0009）で利用者ごとにノートを分けたが、画面には誰でログインしているかが出ていなかった。
- 利用者ごとに名前とアイコンを持っておくと、後で足す機能で使いやすい。

## 決定

- 名前とアイコンは `users/{ログイン ID}` のドキュメント（ノートの親）に持つ。パスワードのある `accounts` とは分け、アカウントを作り直しても消えないようにする。
- API は `GET /me` と `PUT /me`。名前を決めていなければ ID を名前として返す。
- アイコンは、アプリで画像の真ん中を正方形に切り抜き、一辺 256px の JPEG に縮めてから送る。Firestore のドキュメントに base64 でそのまま入れる（1件の上限 1MB に余裕で収まる）。Cloud Storage は使わない。
- 画面は「名前とアイコン」のページを1つ作る。広い画面ではサイドバーのいちばん上（自分のアイコンと名前）、狭い画面では入力ページの上部バーのいちばん右（自分のアイコン）から開く。

## 理由

- アイコンは小さく縮めれば数十KBで、置き場所（バケット）や配信の仕組みを増やすほどのものではない。
- 名前とアイコンだけを読むのに、パスワードのハッシュがあるドキュメントを読ませない。

## 割り切っていること

- アイコンは名前と一緒に毎回まるごと送る・返す。
- 直接編集した行の発言者は、名前を決めても「自分」のまま。
