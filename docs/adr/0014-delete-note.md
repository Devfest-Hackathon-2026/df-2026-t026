# 0014 ノートを消す

- 日付：2026-11-09
- 状態：採用(2026-11-10。API ははせさんの #81、画面は森平)

## 背景

- ノートそのものを消す方法が無い。API に `DELETE /manuals/:id` が無く、画面にも消すボタンが無い。消せるのは、ノートの中の行(ADR 0007)と共有の相手(ADR 0013)だけ。
- 試しに作ったノートや、間違えて作ったノートが一覧に残り続ける。デモの前に片付けることもできない。
- spec の「やらないこと」には入っていない(前の版に戻す・PDF 出力などとは別)。

## 決定(案)

1. **消せるのは持ち主だけ**。共有された人には消すボタンを出さない(API でも持ち主でなければ 404。ADR 0013 の「既定は持ち主だけ」と同じ)。
2. **消すと元に戻せない**。ゴミ箱や取り消しは作らない(前の版に戻すを作らないのと同じく、組織側の機能に近いため)。画面で必ず確かめる。
3. **ノートの下の物をまとめて消す**:本文(`Manual`)と、ノートの下のコレクション `utterances`・`patches`・`checks`・`shares`。履歴は `patches` から作っているので別に消す物は無い(ADR 0008)。
4. **共有していたら、相手の側の索引も消す**:`users/{相手}/shared/{ノート}`。順番は ADR 0013 の「外すときは相手の側を先に」に合わせ、**相手の側の索引 → 持ち主の側の shares → ほかのコレクション → 本文**の順。途中で失敗しても「相手が読めてしまう形」は残らない。相手のサイドバーからは、次に読み込んだときに消える。
5. **画面(フロント)**
   - ノートのページの上部バーに「ノートを消す」を置く(持ち主だけ。枠のボタン、または「共有」と並べたメニューの中。置き場ははせさんと決める)
   - 「消す」は危ない操作の色にする。色は theme.dart の役割の名前のトークンから取る(案:消した行の赤 `removed`)
   - 押すと確かめのダイアログ:題名「このノートを消しますか?」、本文「〇〇(ノートの題名)と、記録・確認・履歴がすべて消えます。共有している人からも見えなくなります。元に戻せません。」、ボタン「消す」(危ない操作の色)・「やめる」
   - 消したら、どこから開いていても(サイドバー・ノート一覧・入力ページ・共有された一覧。上に確認リストや履歴が積まれていても)、ノートの画面とその上の画面を外してノート一覧へ戻る。一覧とサイドバー・「あとで確認」の件数から消える(`changes` を増やして読み直す)
   - 失敗したらトーストで知らせ、ノートは残す
   - docs/spec/button-labels.md に「ノートを消す」「消す」を足す
6. **API(サーバー)**:`DELETE /manuals/:id` → 204。持ち主でなければ 404、無ければ 404。Store に、ノートとその下をまとめて消す関数(例:`removeManual(userId, manualId)`)を足し、MemoryStore と FirestoreStore の両方に作る。Firestore はサブコレクションが親と一緒に消えないので、コレクションごとに消す(件数が多いときは batch)。

7. **消している間に、共有された人が書き込んだ場合**:共有された人も `POST /manuals/:id/edits`・`.../check` を呼べる(ADR 0013)ので、消している途中に来ると、持ち主の無いデータが残りうる。デモの規模では起きにくいので、今は気にしない。

## 見本のノートについて

- `main.ts` は起動のたびに `seedWithHistory(store, 'demo')` を呼ぶが、`seed.ts` 44行の `if ((await store.listManuals(userId)).length > 0) return;` により、**`demo` のノートが0冊のときだけ**見本のノートと記録を入れ直す。
- なので、`demo` で見本のノートを1冊消しても、ほかに1冊でも残っていれば戻ってこない。**全部消したときだけ**、次に起動したとき(Cloud Run のインスタンスが入れ替わったときなど)に見本のノートがそろって戻ってくる。
- (2026-11-10 追記)起動時に見本を入れるのは、メモリ保存(ローカル)のときだけにした。Firestore(本番)では、`demo` のノートを全部消しても戻らない。本番に `demo` のアカウントは無く、起動のたびに Firestore を1回読むぶん待ち受けが遅れていたため。

## 決まったこと(2026-11-10)

- 置き場:ノートのページの上部バーの「共有」の右に「…」(その他)のメニューを置き、その中に「ノートを消す」。狭い画面・広い画面とも同じ。持ち主にだけ出す
- 「消す」の色は消した行の赤 `removed`。消したら、ノートとその上の画面を外してノート一覧を最初の画面(入力ページ)の上に1枚だけ置く。広い画面はサイドバーと同じく動きを付けない
- 見本のノートは上の「見本のノートについて」のとおり(全部消したときだけ戻る)

## 採らなかった案

- ゴミ箱(消したノートを一定期間残す):作る量が増え、データの持ち方も変わる。今はいらない。
- 共有された人も消せる(自分の一覧から外す):それは「共有の解除」で、持ち主の操作として ADR 0013 にすでにある。相手が自分で外す操作は別の話として今回は入れない。
