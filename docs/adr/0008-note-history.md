# 0008 ノートの履歴を、版の幹と食い違いの枝のグラフで見せる

- 日付：2026-11-08
- 状態：採用

## 背景

- ノートは「元の本文＋反映済みのパッチ」として持っている（ADR 0001）が、いつ・誰の言葉で・どう変わったかを順に追える画面がなかった。
- 利用者から、ノートの履歴を git のコミットやブランチのように見たい、版ごとの差分も見たいという要望があった。

## 決定

1. **履歴はアプリで組み立てる。API と保存の形は変えない**
   - `GET /manuals/:id` が返す元の本文・パッチ（反映日時つき）・記録・確認から、反映した順にパッチを当て直し、各版のノートを作る。当て方はバックエンドの `applyPatch` と同じにする。
   - 版管理（Firestore で自前管理か Git か）は決めない。ADR 0001 の「パッチ1件をコミット1件に写せる」をそのまま使う。
2. **幹と枝**
   - 幹は、ノートを作った版と、反映したパッチ。同じ記録から続けて反映したパッチ（確定で2行を1行にまとめたときなど）は1つの版にする。
   - 「ノートのまま」と確定した記録はパッチを作らないが、後で見せる証拠なので、幹に版として残す。
   - 枝は、反映していないパッチ（あとで確認・未反映・反映しない・同じ内容）。記録した時点の版から分かれ、食い違いを確定した記録は、確定した版に合流する。
3. **見せ方**
   - ノート画面の上部バーの「履歴」から開く。新しい順に並べ、広い画面では左にグラフ、右に選んだ版の差分を、狭い画面では押して差分の画面へ進む。
   - 幹と枝の形が一目で見えるよう、1件を同じ高さの1行に詰め、線と点を太く大きくする。行の中身は「誰が・いつ → 何をしたか → 増減か状態」で、収まらなければ本文の末尾を省き、全文は差分の側で見せる。
   - 版の差分は、その版のノート全文に、前の版から増えた行・消えた行の印を付けて見せる。枝は、ノートに入れていない差分だけを見せる。
   - 画面では git の言葉（コミット・ブランチ・マージ）を使わず、「版」「確認」で書く。
   - 見るだけにし、前の版には戻さない（spec の「やらないこと」）。

## 理由

- 食い違いは「ノートから分かれた言い分が、確認して合流する」形で、git のブランチとマージにそのまま重なる。板挟みになったことと、誰に確認して決まったかを一目で追える。
- 保存の形を変えないので、版管理をどちらに決めても画面はそのまま使える。

## 制約・既知の問題

- パッチの当て方を、バックエンド（`api/src/foundation/manual.ts`）とアプリ（`app/lib/history.dart`）の2か所に持つ。当て方を変えるときは両方を合わせる。
- 表示のたびに全パッチを当て直す（ADR 0001 と同じ）。
- 直接書いた行の食い違いは、行がもう幹に入っているので枝にしない。
